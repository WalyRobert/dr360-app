Como Usar o DR 360°

1. Acessar o App

Clique no botão "Acessar o App" para abrir o player DR 360° em uma nova aba do navegador.

2. Carregar Vídeo

Use a interface do app para carregar seu arquivo de vídeo 360° ou URL de streaming.

3. Explorar em 360°

Mova seu mouse ou dispositivo para explorar o vídeo em todas as direções.

4. Modo VR (opcional)

Ative o modo VR para usar com óculos de realidade virtual para imersão completa.

5. Controlar Reprodução

Use os controles para ajustar volume, velocidade e outros parâmetros de visualização.

6. Compartilhar

Download ou compartilhe seus vídeos favoritos através do botão de compartilhamento.
